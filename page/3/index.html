2016 關西行與 Rubykaigi


2016.09.03 - 2016.09.11
第二次與五倍紅寶石的同事們一起來到日本員工旅行並且參加 Ruby 程式語言的盛會 RubyKaigi。

09.03（六） 啟程

從桃園機場出發搭乘虎航前往關西機場，第一次使用快速通關省去了不少排隊時間，但那天不知道什麼原因，飛機延誤一陣子才起飛，抵達日本的時間比原訂晚了許多，而在抵達關西機場，入境後第一件事情就是處理上網。

我的手機是 HTC One M7，這次買的 sim 卡是「STUDIO A x 日本 2.2GB Lite 上網卡（Docomo LTE 2.2GB，8 日）」。本來很擔心手機型號不支援 4G 頻段會不會無法使用，實際在大阪、京都使用後是沒有問題的。

機場交通

  • 南海電鐵空港線 → 天下茶屋站 → 大阪市営堺筋線（北千里行） → 日本橋站

住宿

  • イビススタイルズ大阪 Ibis Styles Hotel Osaka（附早餐）

住的地方離心齋橋非常的近，因此逛起來非常的方便。晚餐吃了一蘭拉麵（來日本不知道幾次終於去吃一蘭），後來又搭車到梅田點了杯麒麟啤酒冰沙，超享受！

店名：キリン一番搾りガーデン
地址：大阪府大阪市北区大深町4-1

09.04（日） 環球影城

第二天的唯一行程就是環球影城。

購票資訊

  • 入場門票＋環球特快入場券 4（標準）

環球特快入場券就是俗稱的「快入通關券」，依券種不同可用的設施也不太一樣。我們買的環球特快入場券 4（標準），可免排的設施有（🚀 表示使用到）：

  1. 哈利波特禁忌之旅（選時段）🚀
  2. 蜘蛛俠驚魂歷險記乘車遊 🚀
  3. 大白鯊 🚀 或 浴火赤子情
  4. 太空幻想列車 或 侏儸紀公園乘船遊 🚀 或 魔鬼終結者

遊玩順序
飛天翼龍（沒玩到） → 哈利波特禁忌之旅 🚀 → shopping → 大白鯊 🚀 → 侏羅紀公園乘船遊 🚀 → 蜘蛛俠驚魂歷險記 🚀 → 飛天翼龍（single） → shopping → 好萊塢美夢 - 乘車遊（single） → 哈利波特魔法世界 → 鷹馬的飛行 → 魔杖表演 → End

其實我們原本想玩的是「好萊塢美夢 - 逆轉世界」，結果 single 區沒有分開，就誤坐到左邊普通版。如果要玩逆轉世界的話，記得要排右邊紅色那台！

就這樣從開園玩到閉園，非常過癮！

09.05（一） 參訪

上午參訪京都的 株式会社アンクシステムズ (ANKH Systems Co., Ltd.)

ANKH 主要研發 pepper 機器人應用，進公司時先是由 pepper 機器人接待，才換真人，非常特別！

接著趕到京都女子大學與資訊工程系老師、學生交流，學到日本綠茶不會苦的泡法。

晚上，我們一行人在日本橋附近吃了 日本牛雜鍋。雖然平常不太敢吃內臟，但這次嘗試覺得沒有腥味，還不錯！

店名：通天閣 もつ鍋屋 道頓堀店
地址：大阪府大阪市中央区日本橋1-1-15

09.06（二） 再訪嵐山

早上退房後移動到京都旅館，趁天亮去嵐山。
三位女生特地體驗浴衣，結果遇到大雨，大家穿著木屐撐傘小步走過渡月橋，拍了不少紀念照。

雨停後本來要去竹林，但天色已暗，改去 嵐電嵐山駅的足湯。購買使用券可泡腳，還附贈印有嵐山字樣的毛巾，當紀念品帶回台灣。

09.07（三） 姬路城

建議從大阪出發比較近，但我們是從京都出發。
推薦購買 Kasai Area Pass 一日券 節省交通費。

姬路城是典型日式城堡，參觀時需脫鞋，會提供塑膠袋裝鞋子。

結束後到京都車站逛 BIC CAMERA、Yodobashi。
原本想買的鍵盤在 BIC CAMERA 沒貨，後來在 Yodobashi 找到，立刻入手！

戰利品

  • FILCO Majestouch MINILA Air 67 鍵 無線藍芽機械鍵盤 - 紅軸

09.08（四） RubyKaigi Day 1

Ruby 程式語言的盛會，場地在 國立京都國際會館（京都議定書簽訂地點）。
第一場 keynote 由 Ruby 之父松本行弘主持。

下午逛贊助商攤位，遇到去年認識的朋友。

晚上官方 After Party，與許多開發者交流。之後女同事們還與 Rails Girl 友人一起榻榻米合宿。

09.09（五） RubyKaigi Day 2

大多時間在準備隔天的 Lighting Talk 講稿。
這天 keynote 的演講主題是 重構程式碼，氣氛幽默而精彩。

晚上有贊助商 After Party，以及 RubyKaraoke。
第一次在日本唱 Karaoke，曲庫裡還有很多中文新歌！

回到旅館後，還請日本朋友教我日文的開場白，互相語言交換。

09.10（六） RubyKaigi Day 3

壓軸就是 Ruby Committers 全員齊聚！

下午持續練習 LT，晚上在熱鬧的 After Party 發表。
主題是介紹 **Ruby Conf Taiwan (12/2–12/3 舉辦)**，希望邀請更多朋友參加。

發表結束後，終於能放鬆乾杯！

09.11（日） 回程

原本規劃去京都御苑，但最後改成睡飽 → 衝機場免稅店 → 回台灣。
在關西機場逛了寶可夢專賣店，吃了烏龍麵，買了伴手禮帶回家。

這趟日本行的心願（鍵盤）已經達成，滿足！
我想我應該很快又會再踏上這片土地的。 :)
